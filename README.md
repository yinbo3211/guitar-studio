# 六弦工坊 · AI 吉他练习室

一个纯前端、零后端、开箱即用的吉他练习网页工具。所有音频处理都在浏览器本地完成，麦克风声音**不会上传、不会保存**（录音棚里的录音只保存在当前页面内存中）。

## 功能一览

| 模块 | 说明 | 是否需要麦克风 |
| --- | --- | --- |
| 调音器 | 自相关（autocorrelation）基频检测，吉他六弦 / 半音阶双模式，±50 音分表盘，A4 基准 432–446 Hz 可调 | 是 |
| 节拍器 | 音频硬件时钟调度，不跑拍；40–240 BPM、TAP 测速、2/4·3/4·4/4·6/8 拍号、四分/八分/三连音/十六分细分，摆锤与强弱拍可视化 | 否 |
| 和弦闯关 | 随机出和弦，对着麦克风逐弦拨弦，实时听音判定；4 个难度、10 题一轮、倒计时、连击加分 | 是 |
| 音阶练习 | 大/小调、五声、布鲁斯、多利亚等 12 种常用音阶与把位，指板高亮根音与音阶音，跟听示范自动播放，开麦克风逐音跟弹、连击计分 | 是（跟弹时） |
| 和弦库 | 22 个常用开放/横按/七/挂留和弦，SVG 指法图，合成扫弦/分解试听，左手琴镜像，6 条经典和弦进行循环伴奏 | 否 |
| 练耳训练 | 单音、音程、三和弦、七和弦四级听辨，选择题作答、正确率统计 | 否 |
| 指板训练 | 0–12 品指板音名图，点击发声；“找音游戏”训练指板记忆 | 否 |
| 录音棚 | 麦克风录音、回听、下载 WebM/MP4 音频 | 是 |

## 文件结构

页面代码按模块拆成 1 个 HTML + 3 个 JavaScript，它们**必须放在同一个文件夹里，缺一不可**：

- `guitar-studio.html`：页面结构与样式，入口文件
- `app-1.js`：通用工具 / 路由 / 调音器
- `app-2.js`：节拍器 / 和弦库
- `app-3.js`：和弦闯关 / 音阶练习 / 练耳 / 指板 / 录音
- `server.ps1`、`启动吉他工具.bat`：Windows 一键本地服务
- `index.html`：GitHub Pages 根地址自动跳转到 `guitar-studio.html`

拷贝或转发时请把上述文件**整个文件夹一起复制**，不要只单独发送 `guitar-studio.html`，否则会因为找不到 `app-1.js / app-2.js / app-3.js` 而白屏。

## Windows 10 一键部署（推荐 Microsoft Edge）

1. 把整个文件夹放到任意位置（如 `D:\guitar-studio`）。
2. **双击 `启动吉他工具.bat`**。
3. 脚本会用 Win10 自带的 PowerShell 启动本地服务（`http://localhost:8765`），并自动打开 Edge。
4. 首次运行会询问是否允许同一 WiFi 下手机访问；需要则输入 `Y`，在弹出的 UAC 窗口点“是”。
5. 关闭黑色命令行窗口即停止服务。

> 为什么不直接双击 HTML？浏览器安全策略要求麦克风只能在 `https://` 或 `localhost` 下使用，因此必须通过本地服务访问。本脚本不安装任何软件，也不联网。

## 手机使用（iPhone / 安卓）

局域网 HTTP 下手机浏览器会禁用麦克风，所以手机端请使用 **GitHub Pages 的 HTTPS 地址**：

1. 仓库推送后，打开仓库 **Settings → Pages**。
2. Source 选择 `main` 分支、根目录 `(root)`，保存。
3. 等待 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/guitar-studio.html`。
4. iPhone 用 Safari 打开，首次调音 / 闯关 / 音阶跟弹时允许麦克风；**iPhone 若无声，请关闭机身左侧静音键**。
5. 页面可“添加到主屏幕”，获得接近 App 的全屏体验。

## 常见问题

- **麦克风按钮点了没反应**：检查地址栏左侧的麦克风权限是否为“允许”；Windows 设置 → 隐私 → 麦克风中允许桌面应用访问。
- **调音器指针乱跳**：周围尽量安静，手机/电脑麦克风距音孔 30–50 厘米，一根弦一根弦拨，避免扫弦。
- **听不到节拍器/和弦声音**：iPhone 关闭侧边静音键；电脑检查系统音量与 Edge 标签页是否被静音。
- **端口 8765 被占用**：用记事本打开 `server.ps1`，修改顶部 `$Port = 8765` 为其他端口。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建、无前端框架、无后端。
- JS 用普通 `<script src>` 标签拆分为 `app-1.js / app-2.js / app-3.js` 引用，无需打包，`file://` 双击或经本地服务均可运行（但麦克风功能仍需 localhost 或 HTTPS）。
- 音频：Web Audio API（OscillatorNode 合成、AnalyserNode 时域采样）。
- 音高检测：经典自相关算法（autocorrelation with quadratic interpolation），本地实时运行。
- 录音：MediaRecorder API。
- 界面：深色霓虹风格，移动端（iPhone 16 Pro 逻辑宽度）与桌面端（Edge）响应式适配。
