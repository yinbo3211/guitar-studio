# 六弦工坊 · 曲谱工坊 用户手册

**适用版本**：V4.4.0 及以上　　**文档版本**：1.0　　**更新日期**：2026-11-25
**对应规格**：`docs/V4.4_SHEET_STUDIO_SPEC.md`
**在线入口**：首页工具卡 / 侧栏导航 /「更多」菜单中的「曲谱工坊」

> 曲谱工坊是六弦工坊的**自制和弦谱**功能：把喜欢的歌按「歌词 + 和弦 + 节奏型」写成一张可试听、可转调、可导出的谱，并保存在你自己的浏览器里。它与内置 231 首弹唱曲库**完全独立**，不会改动任何内置曲目。

## 1. 手册说明

### 1.1 目的

本手册面向**最终使用者**，完整说明曲谱工坊的每一个入口、字段、按钮、语法与边界行为。读完你应当能独立完成：新建一张谱 → 写入歌词与和弦 → 试听 → 保存 → 转调 → 导出备份 → 从曲库进入弹唱。

### 1.2 适用环境

| 项 | 说明 |
|---|---|
| 形态 | 纯网页 App，无需安装、无需构建；桌面浏览器与手机浏览器均可使用 |
| 语言 | 简体中文 / English / 日本語 / 한국어 四语界面，可随时切换 |
| 数据 | 全部保存在**当前浏览器的 localStorage**，不上传服务器、不依赖账号 |
| 音频 | 试听使用浏览器本地合成音，与麦克风无关；麦克风权限仅调音器/音阶等模块需要 |
| 离线 | 已通过 PWA 离线缓存，首次加载后断网仍可打开曲谱工坊（但数据仍在本地） |

### 1.3 符号约定

- **★**：必填项。
- **提示**：提高效率的用法；**注意**：容易踩坑；**警告**：可能造成数据丢失。
- `等宽字体`：源文本标记、按钮名、文件名或键盘按键。
- 文中「曲谱」「谱」「自制谱」均指用户在曲谱工坊创建的 `SheetDoc` 和弦谱。

### 1.4 与内置曲库的区别（重要）

| 对比项 | 曲谱工坊自制谱 | 内置 231 首弹唱曲库 |
|---|---|---|
| 数据来源 | 你自己手写/导入 | 仓库内置数据（`assets/js/data/songlist-data.js`） |
| 谱面来源标记 | `user-chord`（非原曲编配） | `omr` / `melody` / `generated-chords` |
| 歌词与和弦 | 完全由你决定 | 内置，用户不可编辑 |
| 音准评分 / Note Highway | **不接入**（自制谱无旋律音轨，评分无从打分） | 有评分与结算评级 |
| 课程单元 / 难度评级 | **不参与** | 19 个课程单元、三级难度 |
| 试听 | 节奏参考（扫弦 + 逐字高亮） | 完整弹唱演奏 |

> 曲谱工坊**诚实标注**自制谱不是原曲编配：试听只作节奏与和弦进行参考，不代表与原曲逐字对位，也不参与内置曲库的音准评分与 OMR 质量统计。

## 2. 功能总览

### 2.1 三个使用界面

| 界面 | 路由 | 作用 |
|---|---|---|
| 我的曲谱（列表页） | `#/sheetLib` | 新建、搜索、筛选、管理、导入导出、打开试听 |
| 新建 / 编辑器 | `#/sheetEditor` | 表单步填元信息 → 编辑器步写谱面与试听 |
| 曲库「我的曲谱」tab | `#/songbook` | 从曲库侧快速找到自制谱并跳弹唱/编辑 |

另有「全屏试听 overlay」，由列表页「弹唱」或 `#/sheetLib?play=<id>` 直接打开。

### 2.2 数据流向

```
表单字段 ──双向同步──> 头部 {meta} 标记
                          │
画布源文本（gs-chord v1）──> 解析器 SheetFormat ──> 预览渲染 / 试听 / GP 桥接
        │                                              │
        └── 草稿 gs.sheets.draft（800ms 防抖）          └── 练习统计（≥30s）
        └── 正式保存 gs.sheets.v1（SheetStore）
```

编辑器和列表页只保存**源文本**，预览谱面永远是派生视图；这与项目「数据与 UI 分离」的原则一致。

### 2.3 能力清单

| 能力 | 是否提供 | 备注 |
|---|---|---|
| 新建表单（13 字段、胶囊单选、调差提示） | ✅ | 见第 5 章 |
| 分屏画布 / 预览、移动端 tab | ✅ | 见 §6.4 |
| 插入面板五组、`[` 和弦联想 | ✅ | 见 §6.5–6.6 |
| 撤销 / 重做（100 步、2MB 上限） | ✅ | 见 §6.7 |
| 草稿自动保存与恢复卡 | ✅ | 见 §6.8 |
| 语法校验（阻断级 / 警告级） | ✅ | 见 §6.9 |
| 移调预览、变调夹视图、转调另存 | ✅ | 见 §6.10 |
| 试听（速度、移调、段落跳转、逐字高亮） | ✅ | 见第 8 章 |
| 练习统计上报 | ✅ | 单次试听 ≥30s |
| 复制 / 导出单谱 / 全部导出 / 导入 / 打印 | ✅ | 见第 9 章 |
| 曲库「我的曲谱」tab 联动 | ✅ | 见第 10 章 |
| 四语界面、7 套主题 | ✅ | 见第 11 章 |
| 音准评分 / Note Highway | ❌ | 本期不做，见 §2.4 |
| 副歌跳转展开、简化和弦、麦克风跟弹 | ❌ | 本期不做 |

### 2.4 本期已知限制

1. **不接入评分**：自制谱没有旋律音轨，弹唱模式是试听器的全屏化，不产生 Perfect/Good/Miss 判定与结算评级。
2. **跳转记号不展开**：`{soc}` / `{eoc}` /「回到主歌」等 ChordPro 跳转按线性顺序处理，原文保留并提示；请改写为 `{name:副歌}` 段落。
3. **`{x4}` 折叠**：试听只展开 `{x2}`，更大重复遍数显示为徽章不展开（上限保护）。
4. **六线谱块不支持**：`{sot}...{eot}` 保留原文 + 警告，不渲染六线谱。
5. **不参与课程单元与 OMR 统计**：自制谱不解锁课程、不做难度评级、不计入「真实谱面」筛选。
6. **表单步不自动存草稿**：未点「创建」就离开，表单内容不保留（避免产生空谱）。

## 3. 快速上手：3 分钟做出第一张谱

1. 打开首页，点击工具卡 **「曲谱工坊」**，进入「我的曲谱」列表页。
2. 点击 **「新建曲谱」**。
3. 填写两组必填：`歌曲名`（例 `练习小曲`）、`歌手`（例 `自制`）；其余保持默认。
4. 在 `选调 / 原唱调 / 拍速 / 拍号 / 变调夹 / 语言 / 风格 / 编配 / 默认节奏型` 中按需调整（第 5 章有逐项说明）。
5. 点击 **「创建」**，进入编辑器，画布已自动填好头部与 `{name:主歌}` 模板。
6. 把模板最后一行替换成带和弦的歌词，例如在歌词字前输入 `[` 会弹出和弦联想：

   ```
   [C]窗外的麻[C]雀 在[C]电线杆上多嘴
   [Am]你说这一句 [Em]很有夏天的感觉
   [F]手中的铅笔 在[G]纸上来来回回
   ```

7. 右侧预览即时显示和弦在歌词上方的对齐结果；点 **「▶ 试听」** 听节奏；按 `Ctrl/⌘+S` 或顶栏 ✓ **保存**。
8. 返回列表页即可看到带「自制」徽章的曲卡，点 **「▶ 弹唱」** 进入全屏试听。

> **提示**：第一次使用建议先点「导出全部」保存一份 `.json` 到本地，作为 localStorage 被清理时的备份（见 §12.5）。

## 4. 我的曲谱（列表页）

### 4.1 进入方式

- 首页工具卡「曲谱工坊」；
- 左侧栏导航「曲谱工坊」；
- 顶栏「更多」菜单 →「曲谱工坊」；
- 直接访问 `#/sheetLib`。

### 4.2 顶部工具条

| 控件 | 行为 |
|---|---|
| **新建曲谱** | 进入 `#/sheetEditor` 表单步 |
| **导入** | 打开导入弹层（粘贴文本或选 `.txt` / `.json` 文件） |
| **导出全部** | 打包下载单个 `.json`，含全部自制谱 |
| **排序** | 最近编辑（默认）/ 创建时间 / 曲名 |
| **搜索框** | 200ms 防抖，命中 `title` / `artist` / `tags` / `transcriber` |

### 4.3 标签筛选

三行胶囊：**语言 / 风格 / 编配**。每行可点「全部」或某一项；**三行之间取交集**——例如选「国语 + 民谣 + 简化」时，只显示同时满足三者的谱。搜索词与标签筛选也是交集关系。

### 4.4 曲卡内容

每张曲卡包含：曲名、歌手、一行摘要（选调 · 拍号 · 变调夹 · 拍速）、标签胶囊、**「自制」徽章**、相对时间（如「3 分钟前」）。

### 4.5 曲卡五个动作

| 按钮 | 行为 | 注意 |
|---|---|---|
| **▶ 弹唱** | 打开全屏试听 overlay | 不产生评分 |
| **✎ 编辑** | 进 `#/sheetEditor?id=<id>` | 未保存改动会先提示 |
| **⧉ 复制** | 深拷贝 + 新 id，曲名加「(副本)」，时间重置 | 原谱不变 |
| **⇪ 导出** | 下载单谱 `.gsc.txt`（源文本） | 文件名 `<title>-<artist>.gsc.txt` |
| **🗑 删除** | **二次确认**，确认文案含曲名 | **不可撤销**，同时清理对应草稿 |

> **警告**：删除不可撤销。重要曲谱请先「导出」或「导出全部」备份。

### 4.6 空态与直达试听

- 列表为空时显示引导卡：「还没有自制谱，点击上方按钮创建第一首」+「导入文本」次按钮。
- 从曲库跳转过来的链接形如 `#/sheetLib?play=<id>`，会**直接打开全屏试听**，不必再点一次。

## 5. 新建曲谱（表单）

### 5.1 进入与离开

从列表页「新建曲谱」或曲库「我的曲谱」空态引导卡进入。点击 **「取消」** 时，若已填写内容会弹「放弃本次新建？」确认；未改动直接返回列表。

### 5.2 字段逐项说明

| # | 字段 | 控件 | 默认值 | 范围 / 枚举 | 必填 | 说明 |
|---|---|---|---|---|---|---|
| 1 | 歌曲名 | 文本框 | 空 | ≤60 字符 | ★ | 同时写入头部 `{title:}` |
| 2 | 歌手 | 文本框 | 空 | ≤60 字符 | ★ | 写入 `{artist:}` |
| 3 | 制谱人 | 文本框 | 偏好中的昵称 | ≤30 字符 | | 写入 `{transcriber:}`；可在偏好页设置昵称 |
| 4 | 选调 | 下拉 | `C` | 12 个大调 + 小调 | ★ | 实际演唱/使用的调 |
| 5 | 原唱调 | 下拉 | `C` | 同上 | ★ | 原曲调，用于调差换算 |
| 6 | 拍速 | 数字 + 快捷片 | `70` | 40–240，步长 1；快捷 60/70/80/90/100/120 | ★ | 非法值自动钳制并提示 |
| 7 | 拍号 | 下拉 | `4/4` | 2/4、3/4、4/4、6/8、12/8 | ★ | 影响试听每小节拍数 |
| 8 | 变调夹 | 下拉 | 不夹 | 不夹、1 品…7 品 | ★ | 与推荐变调夹联动 |
| 9 | 语言 | 胶囊单选 | 未选 | 纯音乐/国语/粤语/闽南语/英语/法语/日语/韩语/泰语/其他语言 | ★ | 见附录 A |
| 10 | 风格 | 胶囊单选 | 未选 | 流行/古典/爵士/摇滚/民谣/古风/电子/民族/红歌/儿歌 | ★ | 决定默认节奏型推荐 |
| 11 | 编配 | 胶囊单选 | 未选 | 高还原/简化/改编/串烧/原创 | ★ | |
| 12 | 其他标签 | 胶囊多选（≤3） | 未选 | 轻音乐/动漫音乐/游戏音乐/影视歌曲/考级 + 自定义输入 | | 自定义标签按 `Enter` 确认 |
| 13 | 默认节奏型 | 下拉 + 试听 | 按风格推荐 | 14 个预设 | ★ | 「试听」播放该节奏型 2 小节 |

### 5.3 调差提示与推荐变调夹

当 **选调 ≠ 原唱调** 时，表单实时显示换算提示，例如：

> 原唱调 C，选调 C#（升高 1 半音）

同时给出「夹 X 品用 Y 调指法」一键回填按钮，点击后自动设置选调与变调夹，便于用易按指法唱原调。

### 5.4 创建时的校验

- 歌曲名 / 歌手为空 → **「创建」按钮禁用**，字段下方显示红字提示；
- 拍速 <40 或 >240 → 自动钳制回合法区间并 toast 提示；
- 曲名 / 歌手超 60 字符 → 输入框即时截断并计数；
- 必填胶囊（语言 / 风格 / 编配）未选 → 创建不可用；
- 表单未创建前切走路由 → **不写草稿**，刷新丢失表单内容属预期行为。

### 5.5 创建后自动生成的模板

点「创建」后进入编辑器，画布自动填入（字段值来自表单）：

```
{title:练习小曲}
{artist:自制}
{transcriber:}
{key:C}
{originalKey:C}
{tempo:70}
{time:4/4}
{capo:0}
{rhythm:strum-pop-a}
{meta:语言:国语}
{meta:风格:流行}
{meta:编配:高还原}

{name:主歌}
[在这里输入歌词，在歌词字前输入 [ 触发和弦联想]
```

> 表单字段与头部标记**双向同步**：在画布里直接改 `{key:D}`，表单回显也会更新；反之亦然。

## 6. 和弦谱编辑器

### 6.1 界面分区

| 区域 | 内容 |
|---|---|
| 顶栏 | ✓ 保存、曲名与脏标记、＋ 插入、↩ 撤销 / ↪ 重做、⋮ 更多 |
| 左：画布 | 等宽字体 `<textarea>`，直接编辑 `gs-chord v1` 源文本 |
| 右：预览 | 渲染后的谱面、校验面板、试听控制条 |
| 插入面板 | 顶栏 ＋ 或 `Ctrl/⌘+I` 展开，锚定光标插入 |

### 6.2 顶栏控件

| 控件 | 行为 |
|---|---|
| ✓ 保存 | 先跑语法校验 → 无阻断错误则写入 `SheetStore` → toast「已保存」 |
| 曲名区 | 显示 `<title> · <key>调`，未保存改动显示脏标记；点击可快速改曲名/歌手 |
| ＋ 插入 | 展开插入面板 |
| ↩ / ↪ | 撤销 / 重做，禁用态跟随栈状态 |
| ⋮ 更多 | 另存副本、导出文本、导出 JSON、语法帮助、打印、删除曲谱（二次确认） |

### 6.3 画布输入体验

- 等宽字体、3 档字号（14 / 16 / 18px）；
- **中文输入法合成期间禁用解析提交**，避免 IME 卡顿；
- 粘贴 ≥20KB 文本时提示「内容较大，预览已降频」；
- 预览渲染 120ms 防抖，长谱不会逐键卡顿。

### 6.4 分屏与移动端

| 屏宽 | 布局 |
|---|---|
| ≥1024px | 左画布 + 右预览分屏 |
| 480–1023px | 画布 / 预览双 tab 切换 + 浮动「预览」按钮 |
| <480px | 单栏 + 底部工具条，插入面板变底部抽屉，插入后自动收起 |

### 6.5 插入面板五组

选中项插入到**当前光标位置**；打开面板时预览对应位置高亮闪烁 600ms。

| 组 | 项目 | 插入内容 |
|---|---|---|
| 段落名 | 前奏 / 主歌 / 主歌 B / 预副歌 / 副歌 / 副歌 B / 间奏 / 桥段 / 尾奏 / 自定义… | `\n{name:<段名>}\n`；自定义项 ≤12 字符 |
| 节奏型 | 14 个预设（扫弦 / 分解分组，带 ▶ 试听） | `\n{rhythm:<id>}\n` |
| 和弦行 | 4 和弦行 / 8 和弦行 | `\n[C] [G] [Am] [F]\n`（按当前选调调内和弦，可再手改） |
| 备注 | 备注 | `\n{comment:在此输入备注}\n`，并选中文本便于覆写 |
| 重复 | ×2 / ×4 | 行尾追加 `{x2}` / `{x4}` |

### 6.6 `[` 和弦联想

在歌词行输入 `[` 即弹出浮层，继续输入可过滤：

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 在候选中移动 |
| `Enter` / `Tab` | 确认插入完整 `[和弦]` 标记 |
| `Esc` | 关闭浮层 |
| `]` | 自动补全闭合 |

候选来源按权重排序：当前选调调内三和弦 → 内置指法库（22 个和弦，带指法图）→ 七和弦 / 挂留 / 斜线和弦 → 会话内使用频次。输入无法解析的内容（如 `[Cq`）时浮层显示红字「无法识别和弦」，但不强制改正，原文保留。

### 6.7 撤销 / 重做

- 离散操作（插入面板项、联想确认、删除选区、粘贴、转调另存）各压一个快照；
- 连续键入以 **800ms 静默**合并为一个快照；
- 容量 **100 步 / 2MB**，超出丢最旧；每个快照记录光标位置并在撤销后恢复；
- `Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做；
- **不跨保存边界**：保存时清空重做栈，撤销栈保留。

### 6.8 草稿自动保存与恢复

- 画布任何变更 → **800ms 防抖** → 写 `gs.sheets.draft`（含 doc 快照、text、savedAt）；
- 无参数进入 `#/sheetEditor`（新建）时，若存在 **<7 天**的草稿，顶部出现恢复卡：「恢复上次未完成的草稿？《<曲名>》 <相对时间>」，可选 **恢复** 或 **丢弃**；选择恢复后会重建编辑器 DOM 并载入草稿文本；
- 编辑既有谱（带 id）时，草稿比已保存版本更新才提示恢复；
- 多标签页同时编辑同一 id：另一页保存后，当前页顶栏出现黄条「此谱已在其他标签页修改」+ **重新加载 / 覆盖保存**，由你显式选择，不做自动合并；
- 草稿 7 天后自动失效。

> **注意**：草稿是「兜底」不是「版本历史」。正式内容请点 ✓ 保存。

### 6.9 语法校验与保存

**阻断级（红色，阻止保存）**

| 项 | 处理 |
|---|---|
| 文本超 50,000 字符 | 精简或拆分曲谱 |
| 头部缺 `{title:}` | 补写 `{title:}` |
| 解析异常 | 极端结构下出现，检查未闭合标记 |

**警告级（黄色，不阻止保存，可点击跳转到对应行）**

未闭合 `[`、无法识别的和弦修饰、未命中 ID 的节奏型、`capo>7`、重复段名、空段落、未知 `{}` 标记。

校验面板在预览区顶部以折叠条呈现（如「3 个警告 ▾」），展开后逐条列出，点击即滚动并选中画布对应行。

### 6.10 转调、变调夹与另存

| 工具 | 作用 | 是否改源文本 |
|---|---|---|
| **移调预览** `Ctrl+[` / `Ctrl+]` | ±12 半音即时重渲和弦名，降号调按拼写规则归一 | ❌ 不改，刷新/退出还原 |
| **变调夹视图** | 在「实际音高 / 指法」两种显示间切换，如实际 C、夹 2 品 → 显示 D 指法 | ❌ |
| **推荐变调夹** | 按易按指法推荐品位并一键回填 | ✅ 写字段 |
| **转调另存** | 按当前移调值重写整篇和弦标记与头部 `{key:}`，生成新谱，曲名自动加「(移调+2)」 | ✅ 新谱，原谱不变 |
| **另存副本** | 深拷贝为新 id，曲名加「(副本)」 | ✅ 新谱 |

> **提示**：想保留原谱又想换调，用「转调另存」而不是直接改 `{key:}`。

### 6.11 未保存离开保护

脏状态下切路由或关闭页面时弹确认：「有未保存修改，离开将丢失（草稿除外）」；开启草稿时会同时提示「已存为草稿，下次进入可恢复」。

## 7. gs-chord v1 语法速查

### 7.1 四条设计原则

1. 纯文本可手写——记事本就能写，一屏代码 = 一屏谱；
2. 兼容有谱么 / ChordPro 核心子集——`[]` 和弦 + `{}` 格式标记，未知标记容错降级、不报错；
3. 渲染无关——源文本不携带字号/颜色，样式全由渲染层负责；
4. 可序列化回写——保存的永远是源文本，预览是派生视图。

### 7.2 行类型判定顺序

| 顺序 | 判定 | 类型 |
|---|---|---|
| 1 | 整行 `{name:...}` 或行首 `#`（非 `#>`） | 段名 section |
| 2 | 整行 `{rhythm:...}` | 节奏型 rhythm |
| 3 | 整行 `{title/artist/transcriber/key/originalKey/tempo/time/capo/meta:...}` | 头部元信息 meta |
| 4 | 整行 `{comment:...}` 或行首 `#>` | 备注 / 注释 comment |
| 5 | 行尾含 `{x2}` / `{x4}` | 带重复标记的普通行 |
| 6 | 含 `[` 且去掉所有 `[...]` 与 `|` 后无剩余字符 | 纯和弦行 chord-line |
| 7 | 其他 | 歌词行 lyric（行内可嵌和弦） |

### 7.3 和弦标记 `[和弦名]`

- 写在**和弦切入点的歌词字之前**：`[C]窗外的麻[C]雀 在[C]电线杆上多嘴`；
- 根音 `A..G` + 可选 `#` / `b`，修饰支持 `m / m7 / 7 / maj7 / sus2 / sus4 / dim / aug / 6 / m6 / add9 / m7b5 / 5`；
- 斜线和弦 `C/E` 表示低音替换（指法按主和弦出，低音另标注）；
- 大小写规范：根音大写、修饰小写；解析器容错 `♯` / `♭`；
- 纯和弦行可直接写 `[C] [Em] [F] [G] [C]`，`|` 小节线渲染时忽略但保留原文。

### 7.4 段落标记

```
{name:主歌}
#主歌            ← 等价快写
```

内置快捷段名：前奏、主歌、主歌 B、预副歌、副歌、副歌 B、间奏、桥段、尾奏；自定义段名 ≤12 字符。渲染时段名独立成行、加粗并用主题强调色。

### 7.5 头部元信息

```
{title:七里香}
{artist:周杰伦}
{transcriber:小明}
{key:C}
{originalKey:C}
{tempo:70}
{time:4/4}
{capo:0}
{rhythm:strum-pop-a}
{meta:语言:国语}
{meta:风格:流行}
{meta:编配:高还原}
{meta:标签:动漫音乐,考级}
```

- 头部独立成块写在文本**最前**；重复键后者覆盖并给出警告；
- 头部 `{rhythm:}` 是**全谱默认节奏型**；段落名之后的 `{rhythm:}` 只作用于该段，不会回改默认节奏型；
- 未知 `{xxx:…}` 标记**保留原文**、渲染中隐藏，导入不丢数据；
- 表单字段与这些标记双向同步（§5.5）。

### 7.6 节奏型 `{rhythm:}`

- ID 型必须命中 14 个预设（如 `strum-pop-a` / `pick-folk-a` / `strum-du8` / `pick-basic4` / `pick-triplet` / `strum-chuck` / `strum-basic4`），命中才可试听；
- 自由文本型（如 `{rhythm:下 下. 下上 下...}`）仅展示、不发声；
- 未命中且不像自由文本的 ID 会渲染原文并给出校验警告。

### 7.7 备注、重复与注释

| 写法 | 效果 |
|---|---|
| `{comment:女生变调夹 2 品, 男生 3 品}` | 斜体灰色提示行 |
| `#> 这里开始唱下一部分` | 注释行（`#>` 前缀，与段名 `#` 区分） |
| 行尾 `{x2}` / `{x4}` | 「×2」/「×4」徽章；试听只展开 `{x2}` |

### 7.8 未知 ChordPro 标记兼容

| 输入 | 处理 |
|---|---|
| `{soc}` / `{eoc}` | 保留原文 + warning，建议改写为 `{name:副歌}` |
| `{sot}` / `{eot}` | 保留原文 + warning「六线谱块暂不支持」 |
| `{column_break}` / `{new_page}` | 渲染忽略，原文保留 |
| `|` 小节线 | 渲染忽略，纯和弦行内保留可读性 |
| 其他整行 `{...}` | 降级为 meta，保留原文并给 `unknown-marker` 警告 |

### 7.9 完整示例（《七里香》风格转写）

```
{title:七里香}
{artist:周杰伦}
{transcriber:}
{key:C}
{originalKey:C}
{tempo:70}
{time:4/4}
{capo:0}
{rhythm:strum-pop-a}
{meta:语言:国语}
{meta:风格:流行}
{meta:编配:高还原}
{comment:女生变调夹 2 品, 男生 3 品}

{name:主歌}
{rhythm:pick-folk-a}
[C]窗外的麻[C]雀 在[C]电线杆上多嘴
[Em]你说这一句 [Am]很有夏天的感觉
[F]手中的铅笔 在[G]纸上来来回回
[C]我用几行字形容你是我的谁

{name:主歌 B}
{comment:这里就要开始唱下一部分的秋刀}
[Am]秋刀鱼的滋味 [Em]猫跟你都想了解
[F]初恋的香味就这样被我们寻回
[G]那温暖的阳光 像刚摘的鲜艳草莓
[C]你说你舍不得吃掉这一种感觉

{name:副歌}
{rhythm:strum-pop-a}
[Am]雨下整夜 [Em]我的爱溢出就像雨水
[F]院子落叶 跟[G]我的思念厚厚一叠
[Am]几句是非 [Em]也无法将我的热情冷却
[F]你出现在我[G]诗的每一页 {x2}

{name:尾奏}
[C] [Em] [F] [G] [C]
```

### 7.10 常见写法错误对照

| 错误写法 | 现象 | 正确写法 |
|---|---|---|
| `[C` 未闭合 | 校验警告「未闭合 `[`」 | `[C]` |
| `C窗外...` 行内裸和弦 | 当作歌词原文显示 | `[C]窗外...` |
| `{rhythm:xxx-id}` 拼错 | 节奏型徽章显示原文 + 警告 | 用插入面板选择预设 |
| 段名写成 `#>` 开头 | 被当作注释而非段名 | `#主歌` 或 `{name:主歌}` |
| 头部放在段落之后 | 不回灌表单 meta | 头部写在文本最前 |
| `{capo:9}` | 警告 `capo>7` | 0–7 品 |
| 直接改 `{key:D}` 想换调整篇 | 只改调名，和弦不跟着变 | 用「转调另存」 |

### 8.1 入口

### 8.2 控制条

| 控件 | 说明 |
|---|---|
| 播放 / 暂停 | 预览聚焦时 `Space` 亦可切换 |

### 8.3 行为边界

> **注意**：试听是**节奏与和弦进行参考，非原曲对位**。自制谱没有旋律音轨，因此不产生音准评分、不出现 Perfect/Good/Miss 判定与结算评级。

## 13. 常见问题 FAQ

**Q1：曲谱工坊的谱和曲库里的 231 首有什么关系？**
A：完全独立。自制谱存 localStorage，不改动内置数据；曲谱来源标记为 `user-chord`，不参与音准评分与 OMR 质量统计。

**Q2：为什么「弹唱」没有分数和 Perfect/Good 判定？**
A：自制谱没有旋律音轨，无法做音准判定。全屏弹唱是试听器的大字幕模式，提供逐字高亮与和弦参考，不做评分（见 §2.4）。

**Q3：改了 `{key:D}`，为什么和弦名没跟着变？**
A：`{key:}` 只是调名元信息。要让整篇和弦一起转调，用 ⋮ →「按当前显示调另存副本」（转调另存）；只想临时看效果用 `Ctrl+[` / `Ctrl+]` 移调预览，不改源文本。

**Q4：草稿和「保存」有什么区别？**
A：草稿每 800ms 自动写、7 天失效、只作兜底；「保存」才正式写入 `gs.sheets.v1` 并出现在列表页。请养成 `Ctrl/⌘+S` 的习惯。

**Q5：刷新页面后新谱不见了？**
A：先确认是否已点 ✓ 保存；若只写了草稿，重新进入 `#/sheetEditor` 会出现「恢复上次未完成的草稿？」卡片。

**Q6：能直接粘贴有谱么 / ChordPro 导出的谱吗？**
A：可以。`[]` 和弦与常见 `{}` 标记直接识别；`{soc}` / `{sot}` / `{column_break}` 等保留原文并给警告、不破坏其余内容，建议按 §7.8 改写。

**Q7：试听没有声音？**
A：浏览器要求用户先有一次交互才允许播放音频，请先点一下页面再点「▶ 试听」；另检查系统音量与是否静音标签页。若仍无声，可切换到其他主题或刷新后重试。

**Q8：切换语言后我的歌词变成英文了？**
A：不会。曲谱正文是红线内容，永不翻译；只有 UI 标签会变。

**Q9：手机上使用和桌面有什么差别？**
A：功能一致；<1024px 时画布/预览改为双 tab，<480px 为单栏 + 底部工具条，插入面板变底部抽屉。

**Q10：删除后能找回吗？**
A：不能。删除有二次确认但**不可撤销**，请先导出备份。

**Q11：能多人协作或云同步吗？**
A：本期不提供。数据只在本地浏览器，可用「导出全部 / 导入」在设备间手动迁移。

**Q12：`{x4}` 为什么试听没有重复 4 遍？**
A：上限保护，试听只展开 `{x2}`；`{x4}` 渲染为徽章但不展开。

## 14. 故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 「创建」按钮一直灰色 | 必填未齐（曲名/歌手/语言/风格/编配/节奏型） | 逐项检查带红点的必填项 |
| 保存被阻断 | 文本超 50K、缺 `{title:}` | 看校验面板红色条目，点击跳转到行 |
| 预览不更新 | 中文输入法合成中 / 大文本降频 | 结束输入后等待 ≤120ms；≥20KB 时属预期降频 |
| 和弦与歌词没对齐 | 和弦标记写在了歌词字之后 | 和弦写在**切入点字之前**：`[C]窗...` |
| 段名显示为注释 | 用 `#>` 写了段名 | 改为 `#主歌` 或 `{name:主歌}` |
| 节奏型徽章显示原始 ID | ID 未命中 14 个预设 | 用插入面板选择预设，或改写为自由文本型 |
| 另一标签页改动冲突 | 同 id 被多页编辑 | 顶栏黄条选「重新加载」或「覆盖保存」，不要同时编辑 |
| 列表页空白但有谱 | localStorage 被清 / 换浏览器 / 无痕窗口 | 用此前导出的 `.json` 通过「导入」恢复 |
| 移动端按钮被挤出屏幕 | 极窄视口横向溢出 | 393px 已实测无溢出；可尝试旋转或刷新 |
| 试听中途自动停止 | 切换了路由 | 属预期行为，回到曲谱工坊重新点试听 |
